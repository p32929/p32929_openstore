> **An older version.** [Fayaz Bin Salam Portfolio v3](https://openstore.pfay.workers.dev/app/p32929/portfolio-v3) is the portfolio I use today.

Fayaz Bin Salam Portfolio v2 is a free developer portfolio template. Building a personal site from scratch can take days of layout and design work before you even add your projects. With this one you fork the repository, put your details in a single file, and your portfolio is live on GitHub Pages a few minutes later.

What makes it different: everything about you lives in one file, `src/Others/GlobalVars.ts`, so you never touch the layout code. There is no server and no database, and hosting on GitHub Pages costs nothing. Close to 200 developers have starred it and more than 60 have forked it to make their own.

1. **One file to edit:** your name, links, works and skills all go in `GlobalVars.ts`.
2. **Clean layout:** your profile stays on the left, and About, Skills, Works and Contact open on the right.
3. **Colour picker:** visitors can switch the page colours on the fly.
4. **Works on phones:** the side panel folds into a menu on small screens.
5. **Free hosting:** two commands put it on GitHub Pages.
6. **Free and open source** for personal or commercial use.

Great for developers who want a tidy portfolio online today without designing one.

This one is still one of my favourites, even though I don't use it myself any more. I was really bad at CSS back then and honestly hated it, but I still wanted a portfolio that looked like this. It took a lot of searching and trying before it finally came together, and I was so happy when it did. I shared it with all my friends, they loved it, and many of them made their own portfolios with it.

From my first portfolio on, my goal has been the same: anybody should be able to make their own portfolio without changing much. All my portfolio versions are built the same way, with the content kept apart from the layout. Here everything sits in one file, `src/Others/GlobalVars.ts`, so you fork it, put in your own details, and you're done.

How to use it: fork the repository and rename the fork to `your-github-username.github.io`. Clone it, edit `src/Others/GlobalVars.ts`, then run `npm run predeploy` and `npm run deploy`. In your repository settings, point GitHub Pages at the `master` branch. Your portfolio shows up at `https://your-github-username.github.io/` within a few minutes.
