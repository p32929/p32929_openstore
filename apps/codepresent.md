CodePresent is a code presentation maker that turns code into slides and short videos, right in your browser. Putting code on slides usually means pasting screenshots and fighting with formatting, and turning that into a video takes even longer. With CodePresent you write slides with real syntax-highlighted code, or let AI read a GitHub repo or a ZIP file and draft the whole deck, then present it full screen or export it as an MP4.

What makes it different: everything runs in your browser. Your presentations, your API keys and the video encoding all stay on your own computer, and you go from code to a narrated video without any video editing tool. You bring your own keys for any OpenAI-compatible model, and Gemini for the voice.

1. **Slides with real code:** syntax-highlighted code blocks, titles, short descriptions, narration lines and images.
2. **Generate from a repo:** paste a GitHub repository link or upload a ZIP, and AI drafts the whole presentation.
3. **Full-screen play mode:** keyboard controls, with the narration shown as captions.
4. **Export as a video:** MP4 at 1080p or 720p, with optional spoken narration (Gemini text to speech) and your own pause between slides.
5. **Use any AI you like:** an OpenAI-compatible model writes the slides, Gemini reads them out, and image models can draw pictures for them.
6. **Keep your work:** search, rename and sort presentations, and export them as JSON to import again later.
7. **Light and dark mode.**

Great for developers who explain code in tutorials, YouTube videos, team onboarding or talks.

I made CodePresent because I wanted to make explainer videos like the No Boilerplate YouTube channel, whose way of explaining I love. I thought about starting a channel like that, but never did. I used it once or twice, then life happened and I got busy.

Open the web version, make a new presentation or paste a repo link, then press play or Export MP4. You can make and present slides without any API key; the keys are only needed for the AI writing and the voice.
