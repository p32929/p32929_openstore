**Roxaruu is a free, keyboard-first code editor with built-in terminals. Each project keeps its code and all its terminals in one window, and you can open it from any browser.**

## The problem

When you work on several projects at once, every script and server opens another terminal window. Soon you have a pile of windows and no idea which one belongs to which project. Managing them takes more effort than the work. On top of that, most editors make you remember shortcuts or dig through menus to find them.

## How Roxaruu solves it

One window per project, with its code and all its terminals together. Every action has a keyboard shortcut, and the shortcuts that work right where you are always show on screen, so you never have to remember them.

1. **All of a project's terminals in one place,** as tabs or in a grid. On macOS, scripts that open new Terminal windows open tabs in Roxaruu instead.
2. **See what each terminal is doing:** printing, running, or gone quiet.
3. **Made for Claude Code and other AI coding agents.** You are told when one has finished or needs you, even while you look at something else.
4. **Shortcuts on screen.** Press F1 for every shortcut, or Ctrl+Shift+P (⇧⌘P on a Mac) to find any command by name. Change any shortcut you like.
5. **A fast code editor:** syntax highlighting for 23 languages, split view, find and replace, go to file and project-wide search.
6. **Opens huge files instantly,** and files reopen where you left them.
7. **Code from anywhere.** Turn on remote access, set a password, and open the same window in any browser, even on a phone or a Linux server with no screen.
8. **Make it yours:** colour themes, fonts, a clipboard history, a to-do list and recent folders.
9. **Free and open source.**

## Who it is for

1. Developers who run many projects, servers and scripts at the same time.
2. People who work with AI coding agents like Claude Code in the terminal.
3. Anyone who prefers the keyboard over the mouse.
4. Developers who want to reach their editor and terminals from another computer or a phone.

## Good to know

Roxaruu runs on macOS, Windows and Linux. It is not a full IDE, but what it does, it does well. To install on Linux, see the [project page](https://github.com/p32929/roxaruu#install).
